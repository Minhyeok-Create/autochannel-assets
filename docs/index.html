프로그램 코드를 올린 비공개 저장소 (아이디/저장소이름)

토큰 만드는 법 (1회, 3분)

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. 이름 dashboard, 만료 1년, Repository access: Only select repositories → 자동화 저장소 하나만
  3. Repository permissions: Contents: Read and write, Actions: Read and write (Metadata는 자동)
  4. 생성된 토큰을 위에 붙여넣기

토큰은 이 브라우저에만 저장되고 GitHub 외 다른 곳으로 전송되지 않습니다. 공용 PC에서는 '로그인 유지'를 끄세요.
